* Byte Machine

[[https://github.com/Kiyomi-Computation-Systems/byte-machine/actions/workflows/ci.yml][https://github.com/Kiyomi-Computation-Systems/byte-machine/actions/workflows/ci.yml/badge.svg]]

A generator of fast, resumable, byte-level parsers for Chez Scheme, in the
manner of [[https://github.com/nodejs/llparse][llparse]].

#+begin_quote
✨ *AI Disclosure:* LLMs are used extensively in the planning and development of this project.
#+end_quote

** What it is

You describe a parser as a state machine over bytes, built with ordinary Scheme
procedures. Byte Machine checks it and emits a plain R6RS library that parses
input incrementally: feed it bytes as they arrive, in any split, and it calls
you back. The generated library depends only on =(rnrs)= and a small runtime,
=(byte-machine runtime)=. It never needs the builder, verifier or generator at
run time.

It is a toolkit for writing protocol and format parsers, not a parser for any
one format. [[https://github.com/Kiyomi-Computation-Systems/chez-httparse][chez-httparse]], an HTTP/1.x parser built with it, passes llhttp's
conformance corpus at every chunk size.

** What it gives you

- *Resumable parsing.* Every state survives a feed boundary, so a token split
  across any number of feeds parses exactly as it would in one buffer.
- *No input buffering.* Spans (a header name, a body) are delivered to your
  callbacks as ranges into the bytevector you fed. The runtime keeps no
  reference to it after the feed returns, and the generated per-byte path
  allocates nothing.
- *The pieces protocol parsers need.* Byte dispatch, byte classes, exact
  sequences, keyword tables (prefix-tolerant, optionally case-insensitive),
  unsigned-integer fields with overflow-checked accumulation, counted consumption
  (read N bytes of body), callbacks that can pause the parser, and spans.
- *Precise errors.* An error record names its code, the node, the stream offset,
  whether the fault was a byte, a feed boundary or end of input, and any span it
  cut short.
- *A machine you can inspect.* The machine is an immutable data structure, not a
  grammar file or a macro expansion, so it can be built, printed and tested like
  any other value.

** What makes it different

- *Verified before it is generated.* Every machine passes a mandatory verifier
  before any code is emitted. It reports unreachable nodes, zero-progress loops
  that would spin forever, end-of-input paths that end in the wrong place,
  malformed spans and invalid field operations: [[file:.reference/verifier-diagnostic-catalog.md][33 diagnostic codes]], each with
  the offending path.
- *A reference interpreter to test against.* An independent interpreter executes
  the same machine. The test harness runs it beside the generated parser and
  requires the two to agree, so a generator bug shows up as a disagreement.
- *Deterministic, reviewable output.* The same machine always emits the same
  source bytes. You can commit the generated parser and review changes as a diff.
- *Pure Scheme.* No C and no FFI. The library and the generated parsers use only
  R6RS, so they also run on Guile and Racket (see [[*Portability][Portability]]).

** Quick start

A machine is built with =(byte-machine graph)=, verified and compiled, then
emitted as a library that depends only on =(byte-machine runtime)=:

#+begin_src scheme
(import (byte-machine graph) (byte-machine verify) (byte-machine compile))

;; a parser that accepts exactly the byte 'A' (0x41), then stops
(define m
  (make-machine 'simple 'start '() '() '()
    (list (make-error-declaration 'eof 'unexpected-eof "unexpected end of input" #f)
          (make-error-declaration 'rejected 'unexpected-byte "expected 0x41" #f))
    (list (make-byte-dispatch-node 'start
            (list (make-byte-case (make-exact-byte-matcher #x41)
                                  (make-edge 'accept 'advance) #f))
            (make-edge 'reject 'reexecute) 'eof-stop #f)
          (make-stop-node 'accept #f)
          (make-error-node 'reject 'rejected #f)
          (make-error-node 'eof-stop 'eof #f))
    'eof #f))

(compilation-ok? (compile-machine m '()))   ; => #t
#+end_src

The runnable version, which constructs, compiles, emits, loads and feeds bytes,
is [[file:examples/generate-simple-machine/][=examples/generate-simple-machine/=]]:

#+begin_src bash
chez --libdirs src --program examples/generate-simple-machine/generate.sps
#+end_src

Next, read the [[file:.reference/source-ir-and-builder.md][source IR and builder reference]] for every constructor, and the
[[file:.reference/generated-code-integration-chez.md][generated-code integration guide]] for importing and running a generated parser.

** Requirements

- Chez Scheme 10.4.1 or newer (the full system, not Petite)
- CMake 3.26 or newer, to build and run the tests

Verified on macOS arm64. Linux amd64, Windows amd64 and Linux arm64 are
supported targets that are not CI-verified; see the [[file:.reference/portability-matrix.md][portability matrix]].

** Building and testing

#+begin_src bash
make build
#+end_src

#+begin_src bash
make test
#+end_src

=make help= lists every target. =make test-all= runs the complete selection,
including the mutation suite, and =make doctor= reports the discovered toolchain.
Without =make= (on Windows, for instance), use the CMake presets directly:

#+begin_src bash
cmake --preset dev
#+end_src

If discovery cannot find Chez, point it at the executable:

#+begin_src bash
cmake --preset dev -DBYTE_MACHINE_CHEZ_EXECUTABLE=/absolute/path/to/scheme
#+end_src

** Portability

Everything under =src/byte-machine/= imports only =(rnrs)=, and a generated
parser imports only =(rnrs)= and =(byte-machine runtime)=. Only the build and
test layer is Chez-specific. Checked locally, without CI: on Guile 3.0.11 the
toolchain runs unchanged, and on Racket 9.3 it runs once each =.sls= starts with
=#!r6rs=. On both, the emitted library is byte-identical to Chez's.

#+begin_src bash
guile --r6rs -L src your-program.scm
plt-r6rs ++path src your-program.sps
#+end_src

You can also generate on Chez and deploy only the emitted =.sls= with
=(byte-machine runtime)=.
