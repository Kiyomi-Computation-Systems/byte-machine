# docs/

This directory is reserved for **public** documentation.

The project's internal development record lives in hidden top-level directories:

- [`/.plans`](../.plans/) — implementation plans and milestone designs
- [`/.decisions`](../.decisions/) — architecture decision records
- [`/.reference`](../.reference/) — the v0.1 reference documentation set

See [`AGENTS.md`](../AGENTS.md) for the layout convention.
